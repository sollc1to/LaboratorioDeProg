# LaboratorioDeProg

LaboratorioDeProg es un proyecto académico de desarrollo web en proceso, orientado al monitoreo de servidores mediante conexiones SSH. El objetivo del proyecto es permitir 
la obtención y visualización de información relevante de servidores remotos a través de una interfaz web, aplicando conceptos de programación, sistemas operativos y redes.
El desarrollo se realiza utilizando JavaScript y Node.js para el backend, junto con tecnologías web básicas para la interfaz (HTML, CSS JavaScript), este proyecto se
ejecuta en un entorno Linux y hace uso de conexiones SSH para comunicarse de forma segura con los servidores monitoreados.
Actualmente se encuentra en desarrollo y continúa evolucionando a medida que se incorporan nuevas funcionalidades y mejoras.
